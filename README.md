# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce web application built with React and Redux Toolkit. It allows users to browse a wide variety of indoor and outdoor plants, manage their shopping cart quantities, and simulate a plant purchasing experience.

## Features
- Landing page with background image and "Get Started" call-to-action.
- Plant product catalog categorized by type.
- Add items to the shopping cart with dynamic cart count badges.
- Increment, decrement, and remove items from the shopping cart.
- Total cost calculation.
